App 1 upgrade brief

What this artifact proposes for apps/website — Soft Structuralism + Z-Axis Cascade, keeping PIFH brand colors.

Replace

Template tells that read as generic SaaS.

  • Inter body → Plus Jakarta Sans
  • Lucide thick strokes → 1.25px line icons
  • Sticky edge-to-edge nav → floating island
  • Flat bordered cards → double-bezel + cascade
  • ease-in-out → custom cubic-bezier

Keep

Brand equity that already works.

  • Navy / Teal / Green / Gold palette
  • Fraunces for display (warm trust)
  • Mission voice & “not insurance” clarity
  • Live plan data wiring
  • Framer Motion reveal infrastructure

Ship order

Highest visual ROI first.

  • 1. Hero + island nav (this artifact)
  • 2. Plans page card system
  • 3. About community gallery
  • 4. Global icon + type tokens
  • 5. Footer + secondary pages
