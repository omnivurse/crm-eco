App 3 upgrade brief

Proposed direction for apps/member-portal — Soft Structuralism + Asymmetrical Bento. Warm trust for members, not dark SaaS.

Replace

Generic portal chrome that feels like every other dashboard.

  • Inter → Plus Jakarta Sans
  • Lucide → Phosphor Light
  • Sticky edge header → floating island
  • Flat bottom tab bar → floating dock island
  • 2-col equal cards → 12-col asymmetrical bento
  • Blue gradient hero → teal→green brand wash

Keep

Member workflows that already work.

  • Spruce teal primary (#0b6d85)
  • Dashboard card data model
  • PWA / bottom-nav IA
  • Tenant branding injection
  • “Not insurance” reminder

Ship order

Highest daily-use surface first.

  • 1. Shell (island nav + dock)
  • 2. Dashboard bento
  • 3. Needs / billing cards
  • 4. Coverage & services
  • 5. Support + enrollment polish
