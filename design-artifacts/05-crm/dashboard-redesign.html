App 5 upgrade brief

Proposed direction for apps/crm — Ethereal Glass + Asymmetrical Bento. A dark OLED workbench for operators — not another light gray Zoho clone, and not the same Editorial Split as App 2.

Replace

Flat slate admin chrome that feels dated at scale.

  • Inter → Plus Jakarta Sans
  • Lucide → Phosphor Light
  • Edge sticky top bar → floating glass island
  • Flat module strip → glass pill tabs
  • Hard sidebar rail → glass contextual rail
  • Equal 4-col KPI row → asymmetrical bento
  • Light slate-50 canvas → OLED void + cyan/emerald mesh

Keep

CRM IA and power features that already work.

  • CrmShell: top bar · module tabs · contextual sidebar · bottom bar
  • Command palette (⌘K)
  • Module stats / tasks / activity / imports
  • Offline banner + sync toasts
  • Gizmo / create flows / record detail shells

Ship order

Highest daily-use surface first — CRM is huge.

  • 1. Shell tokens + glass island top bar
  • 2. Module tabs + contextual rail
  • 3. Dashboard bento
  • 4. List / pipeline / record chrome polish
  • 5. Login + bottom bar polish
